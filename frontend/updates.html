Changelog

What's new

Every update since launch, most recent first.

June 3, 2026 latest
  • new Vercel Edge Middleware — when you share a link to a movie or show, Discord, Twitter, Telegram, and Google now see the real title, description, and poster image instead of a generic placeholder
  • new JSON-LD structured data — Movie and TVSeries schema injected on the player page, helps Google understand what's on the page
  • new Source quality badge — player hero now shows CAM, WEB, HD, or AIRING based on TMDB release dates so you know what quality to expect before watching
  • new Trakt.tv scrobbling — connect your Trakt account in Settings and everything you watch automatically syncs to your Trakt history
  • fix Player auto-resume — fixed black screen when resuming; timestamp is now applied correctly to the video URL and cleared after use so it doesn't stick across episodes
  • fix Adblocker popup — dismissed permanently on any close action, no longer required a separate "never show again" checkbox
  • new Adblocker prompt — detects whether you're on desktop or mobile and shows the right install instructions (uBlock Origin vs Brave/Firefox Focus)
  • new Italian and Russian — adblocker prompt and player UI translated into IT and RU, joining the existing multi-language support
  • new Contact / Feedback page — added to the top nav; messages save to the database so nothing gets lost even if email fails
  • fix Favicon, anime API endpoint, and cold start "warming up" message improvements
June 2, 2026
  • new Live sports — new Live page with real-time scores, match schedule, favorites, date picker, league filter, sport icons, and theater mode. Sources: Streamed.pk and EmbedSportex
  • new Live sports PWA — installable as a standalone app on Android and desktop
  • new Live sports i18n — Russian and Italian translations added to the live page
  • fix Live page: team banner images, sport gradient cards, mobile layout, source switching, and several security issues
  • new UTM redirect links — /go/freemediaheckyeah, /go/anime, and others for tracking traffic from community posts
  • perf Analytics: added utm_content dimension to campaign tracking; campaign table now shows all-time data
June 1, 2026
  • new 90-day sessions — stay logged in for 3 months without being kicked out
  • new Episode notifications — follow a TV show and get an email when a new episode drops
  • new Tiered TMDB cache — popular content cached longer, reduces API calls and speeds up page loads
  • new Clean URLs — /watch/movie/550 instead of /player.html?type=movie&id=550
May 31, 2026
  • new Smart server auto-failover — player detects when a source fails via postMessage and silently switches to the next one. Last working server is remembered per title
  • new Profile picture upload — change your avatar directly from the account page (powered by Cloudinary)
  • new My List redesign — filters by type, sort by date/title, search, bulk remove, and a randomizer button that picks something to watch
  • new Analytics dashboard redesign — trend charts, hourly heatmap, UTM campaign builder, CSV export, OS/city/user growth charts
  • new 15 player improvements — lazy tab loading, sticky player bar, watch progress bar, share button, report broken button, reload button
  • new Search overhaul — typeahead suggestions, people search (actors/directors), multi-source results, search history pills
  • new Coming soon badge — titles not yet released show a "Coming Soon" badge and the Watch button is disabled
  • sec Fixed 8 security vulnerabilities identified in code review — rate limit bypass, admin route exposure, and others
  • fix My List: 8 bugs fixed including login gate, visible toasts, and correct error messages
May 30, 2026
  • new Password reset and email verification — forgot password flow via email, plus verify-your-email on signup
  • new UTM campaign tracking — analytics tracks where visitors come from (Reddit, Lemmy, etc.) and shows it in the dashboard
  • new 10 player improvements — real cast credits, episode list, ratings, load more button, keyboard shortcuts, search history
  • perf Fetch timeouts on all API calls — sleeping Render backend now triggers the retry UI immediately instead of hanging
  • fix Crash loop on Render caused by ua-parser-js — replaced with inline UA parser
May 2026 launch
  • new Multi-language UI — English, Italian, and Russian throughout the entire interface
  • new Multiple themes — Pulse, Noir, Marquee, and more with dark/light modes and accent color picker
  • new User accounts — optional signup; required only for My List, Keep Watching, and episode notifications
  • new Keep Watching — automatically picks up where you left off across sessions and devices
  • new 10+ embed servers — vidsrc, embed.su, autoembed, vidlink, and more, with automatic failover if one source doesn't work
  • new Android TV and spatial navigation — d-pad/remote control support for TV browsers
  • new Mobile-first layout — bottom navigation bar, swipe gestures on hero, responsive design throughout
  • sec TMDB API key moved to backend proxy — no longer exposed in frontend source code
  • new Site launched — movies, TV shows, and anime. Free, no sign-up required, zero ads
